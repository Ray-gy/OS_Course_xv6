## RISC-V assembly 问题

### 1. 哪些寄存器包含函数的参数？例如，哪个寄存器在main调用printf时保存13？

根据call.asm中的代码分析：

在main函数中：
```assembly
printf("%d %d\n", f(8)+1, 13);
```

对应的汇编代码：
```assembly
24:	4635                	li	a2,13        # a2寄存器保存13
26:	45b1                	li	a1,12        # a1寄存器保存f(8)+1的结果
28:	00000517          	auipc	a0,0x0      # a0寄存器保存格式字符串地址
2c:	7a850513          	addi	a0,a0,1960 # 7d0 <malloc+0x102>
```

**答案：**
- a0寄存器保存格式字符串的地址
- a1寄存器保存第一个参数（f(8)+1 = 12）
- a2寄存器保存第二个参数（13）

在RISC-V中，函数参数按顺序保存在a0, a1, a2, a3, a4, a5, a6, a7寄存器中。

### 2. 在main的汇编代码中，对函数f的调用在哪里？对函数g的调用在哪里？（提示：编译器可能会内联函数）

查看main函数的汇编代码：

```assembly
void main(void) {
  1c:	1141                	addi	sp,sp,-16
  1e:	e406                	sd	ra,8(sp)
  20:	e022                	sd	s0,0(sp)
  22:	0800                	addi	s0,sp,16
  printf("%d %d\n", f(8)+1, 13);
  24:	4635                	li	a2,13        # 直接加载13到a2
  26:	45b1                	li	a1,12        # 直接加载12到a1
```

**答案：**
- 对函数f的调用：**没有直接的函数调用**，编译器将f(8)内联了，直接计算结果为12
- 对函数g的调用：**没有直接的函数调用**，编译器将g(8)内联了，直接计算结果为11，然后+1得到12

编译器优化将f(8)+1 = g(8)+1 = (8+3)+1 = 12直接计算出来，避免了函数调用开销。

### 3. printf函数位于什么地址？

在main函数中调用printf的汇编代码（在call.asm中的行数）：
```assembly
48行: 30:	00000097          	auipc	ra,0x0      # 加载PC相对地址到ra
49行: 34:	5e6080e7          	jalr	1510(ra) # 跳转到ra+1510
```

**答案：**
printf函数的地址是：**0x616**

计算过程：
- auipc ra,0x0：将PC+0加载到ra寄存器，此时ra = PC + 0 = 0x30
- jalr 1510(ra)：跳转到ra + 1510 = 0x30 + 1510 = 0x616
- 所以printf函数位于地址0x616

验证：在call.asm第1058行可以看到printf函数的定义确实在地址0x616处：`0000000000000616 <printf>:`

### 4. 在main中jalr到printf后，寄存器ra中立即包含什么值？

**答案：**
ra寄存器包含：**0x38**

解释：
- jalr指令会将下一条指令的地址保存到ra寄存器
- jalr指令位于0x34，下一条指令位于0x38
- 所以ra = 0x38

### 5. 运行以下代码的输出是什么？

```c
unsigned int i = 0x00646c72;
printf("H%x Wo%s", 57616, &i);
```

**答案：**
输出：**He110 World**

解释：
- 57616的十六进制是0xe110，所以%x输出"e110"
- 0x00646c72在小端序下，按字节读取是：72 6c 64 00
- ASCII码：72='r', 6c='l', 64='d', 00='\0'
- 所以%s输出"rld"
- 最终输出："He110 World"

### 6. 如果RISC-V是大端序而不是小端序，为了产生相同的输出，你需要将i设置为什么值？你需要改变57616吗？

**答案：**
- 如果是大端序，需要将i设置为：**0x726c6400**
- 不需要改变57616

解释：
- 大端序下，0x726c6400按字节读取是：72 6c 64 00
- 这与小端序下0x00646c72按字节读取的结果相同
- 57616的值不需要改变，因为它是整数，不受字节序影响

### 7. 在以下代码中，'y='后面会打印什么？（注意：答案不是一个具体的值。）为什么会发生这种情况？

```c
printf("x=%d y=%d", 3);
```

**答案：**
y=后面会打印：**一个未定义的值**

**原因：**
- printf期望两个参数，但只提供了一个参数（3）
- 第一个%d（x=%d）正确打印3
- 第二个%d（y=%d）会读取栈上未初始化的内存位置，打印出垃圾值
- 这是未定义行为，可能导致程序崩溃或打印随机值
